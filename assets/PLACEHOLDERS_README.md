Placeholder sprites included as SVGs. GameMaker may not import SVG directly; use an image editor (Inkscape/Photoshop) to export PNGs at desired sizes and import into GameMaker. These are small, permissive placeholders to run the prototype visually. If you want I can also add PNG exports.

Suggested sprite sizes:
- spr_bike: 128x64
- spr_ground tile: 256x128 (tileable)
- spr_ramp: 128x64

To convert inside the repo: open the SVGs in an editor and "Export as PNG" at the sizes above and import into your GameMaker project as sprites named spr_bike, spr_ground, spr_ramp.
