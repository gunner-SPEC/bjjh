# GameMaker 2.5D Bike Prototype

This branch implements a single-player prototype for a 3rd-person bike game in GameMaker (2.3+). It uses 2D movement on the room plane (x/y) with a vertical 'z' variable for jumps and airborne behavior to produce a 3rd-person feel.

Open the project in GameMaker v2026, import the scripts, create the objects and sprites, and run the sample room.

See ProjectSetup.md for detailed import instructions.
