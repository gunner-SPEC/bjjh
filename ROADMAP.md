# ROADMAP

Short roadmap for gamemaker-full-sp branch

Milestone 1 (current commit)
- Core bike controller (obj_bike)
- Camera follow (obj_camera)
- UI prototype (obj_ui)
- Data for 3 bike archetypes + upgrades
- Config file for quick tuning

Milestone 2 (next commits)
- Add placeholder sprites and 3 sample rooms (forest, mountain, urban rooftop)
- Add simple upgrade UI to equip attachments and see stat changes
- Add customization UI (bike colors, character outfit selection)

Milestone 3
- Polish physics (terrain-aware suspension using obj_ground collisions)
- Add sound FX and simple particle effects for jumps/landings

Milestone 4
- Multiplayer POC (UDP position sync) in separate branch gamemaker-mp-poc
